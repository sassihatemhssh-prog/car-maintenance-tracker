# سيارتي — تطبيق متابعة السيارة

تطبيق ويب عربي لتسجيل الوقود والصيانة وغسيل السيارة ومواعيدها، قابل للتثبيت على Android.

## التثبيت على Android
بعد نشر GitHub Pages افتح الموقع في Chrome، ثم اختر القائمة ⋮ → «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق». افتح الموقع أول مرة باتصال الإنترنت. تُحفظ البيانات في هذا الجهاز وهذا المتصفح فقط؛ استخدم زر «تصدير نسخة» للاحتفاظ بنسخة احتياطية.

تظهر حالة المواعيد عند فتح التطبيق. هذا الإصدار لا يرسل إشعارات خلفية تلقائية عندما يكون مغلقًا. تذكير الإطارات بالكيلومترات لا يغني عن فحص حالتها أو اتباع توصيات الشركة الصانعة.
