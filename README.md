# سيارتي — Citroën C4 ديزل

تطبيق ويب عربي لتسجيل صيانة السيارة والوقود والغسيل والمواعيد. يدعم أكثر من سيارة، وتقدير استهلاك الوقود بين التعبئات الكاملة، وملخص المصروفات، ونسخ JSON الاحتياطية وتصدير CSV. البيانات محفوظة محليًا في المتصفح.

## بيانات السيارة الافتراضية
- Citroën C4، رمز النوع/الصنع LC9HXC
- سنة الصنع: 2009؛ تاريخ أول جولان: 28/01/2009
- الوقود: غازوال؛ القوة الجبائية: 5 أحصنة
- العداد المبدئي: 224,088 كم
- الفحص الفني: 13/03/2027؛ تجديد الإذن بالجولان: 04/03/2027؛ التأمين: 04/07/2027
- رقم الهيكل غير مضمن في ملفات الموقع العامة. أدخله اختياريًا في إعدادات جهازك فقط. تذكّر أن ملف النسخة الاحتياطية JSON يتضمن البيانات المحلية.
- فترات الزيت والإطارات تقديرية وليست توصية خاصة بالمحرك؛ راجع دليل الصيانة المطابق لرمز المحرك.

## التشغيل
للتجربة افتح `index.html` في متصفح حديث. لتفعيل تثبيت PWA وService Worker يلزم تقديم الموقع عبر HTTPS أو `localhost`؛ فتح الملف مباشرة لا يفعّل هذه الميزات عادةً.

## النشر على GitHub Pages
انشر ملفات المستودع كملفات ثابتة على HTTPS. بعد تفعيل GitHub Pages من إعدادات المستودع، افتح الموقع في Chrome على Android واختر ⋮ → «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق». افتح الصفحة مرة أولى مع الإنترنت لتخزين ملفات الواجهة للاستخدام دون اتصال.

## الاستخدام والخصوصية
- سجّل تعبئات الوقود باللترات والعداد، واستخدم علامة «تعبئة كاملة»؛ يتطلب تقدير لتر/100 كم تعبئتين كاملتين على الأقل. النتيجة تقريبية.
- المواعيد تُعرض عند فتح التطبيق؛ لا توجد إشعارات خلفية تلقائية عند إغلاقه.
- «نسخة احتياطية» ينزّل JSON لكل السيارات والسجلات. الاستيراد يستبدل البيانات المحلية بعد التأكيد.
- CSV يصدّر سجلات السيارة الحالية. البيانات لا تُرسل إلى خادم، لكن مسح بيانات المتصفح قد يحذفها؛ احتفظ بنسخة احتياطية.
