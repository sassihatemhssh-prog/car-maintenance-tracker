# سيارتي — Citroën C4 ديزل

تطبيق ويب عربي لتسجيل صيانة السيارة والوقود والغسيل ومواعيدها. يدعم أكثر من سيارة، وتقدير استهلاك الوقود بين التعبئات الكاملة، وملخص المصروفات، ونسخ JSON الاحتياطية وتصدير CSV. البيانات محفوظة محليًا في المتصفح.

## البدء
افتح `index.html` في متصفح حديث للتجربة. لميزات التثبيت والعمل دون اتصال، انشر الملفات على HTTPS (مثل GitHub Pages) أو شغّل خادمًا محليًا. فتح الملف مباشرة لا يضمن تفعيل Service Worker أو إمكانية تثبيت PWA.

## تثبيت Android
بعد نشر الموقع على HTTPS، افتحه في Chrome ثم اختر القائمة ⋮ → «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق». افتحه مرة أولى مع اتصال الإنترنت ليتم تخزين واجهة التطبيق للاستخدام دون اتصال.

## بيانات السيارة الافتراضية
- Citroën C4، ديزل (يمكن تعديل الشركة والطراز ونوع الوقود والسنة من الإعدادات)
- العداد: 224,088 كم
- موعد الفحص الفني: 13/03/2027
- خلاص الإذن بالجولان: 04/03/2027
- التأمين: 04/07/2027
- فترات الزيت والإطارات الافتراضية تقديرية فقط؛ راجع دليل الصيانة المطابق لسنة السيارة ورمز المحرك.

## الوقود والاستهلاك
سجّل العداد واللترات لكل تعبئة، وضع علامة «تعبئة كاملة» عند ملء الخزان. يحتاج تقدير لتر/100 كم إلى تعبئتين كاملتين على الأقل؛ سجّل أيضًا التعبئات الجزئية بينهما لتحسين التقدير. النتيجة تقديرية وليست قياسًا رسميًا.

## النسخ الاحتياطية والخصوصية
- «نسخة احتياطية» ينزّل JSON يشمل السيارات والسجلات.
- «استيراد» يستبدل البيانات المحلية بعد طلب التأكيد.
- CSV يصدّر سجل السيارة المحددة.
- لا تُرسل البيانات إلى خادم؛ حذف بيانات المتصفح قد يمحوها، لذا احتفظ بنسخة احتياطية.

## التنبيهات
حالة المواعيد تظهر عند فتح التطبيق. هذا الإصدار لا يرسل إشعارات خلفية تلقائية عندما يكون التطبيق مغلقًا. التواريخ والفترات قابلة للتعديل/الإدخال حسب احتياجك.
